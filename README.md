# The Magnificent Three — Brain Tumor Classification System

Brain-tumor classification from MRI images, wrapping a scikit-learn model zoo behind a Flask API and a Flutter desktop/mobile GUI. A Streamlit dashboard is also included for side-by-side model comparison (accuracy, learning curves, confusion matrices).

Classifies three tumor types: **Meningioma**, **Glioma**, **Pituitary Tumor**.

## 🚀 Features

- **Six classical ML models** trained on the same task for comparison:
  Decision Tree, Naive Bayes, Logistic Regression, Random Forest, SVC, K-Nearest Neighbors
- **Real-time classification** via Flask REST API
- **Cross-platform Flutter GUI** — Windows, macOS, Linux, iOS, Android, Web
- **Streamlit dashboard** for model evaluation (learning curves, confusion matrix, classification report, ad-hoc prediction on uploaded images)
- **Confidence scores** alongside predictions

## 🏗️ Project Structure

```
the-magnificent-three/
├── ML_Model/                       # Python backend
│   ├── Brain_Tumor.ipynb           # Notebook that trains the .pkl models
│   ├── app.py                      # Streamlit model-comparison dashboard
│   ├── FlaskForClassification.py   # Classification REST API (port 5000)
│   └── FlaskForRegression.py       # Regression REST API (port 5001)
├── flutter_ml/                     # Flutter frontend (Dart)
│   ├── lib/                        # Source
│   └── pubspec.yaml                # Flutter dependencies
├── test-images/                    # Sample MRI images for quick testing
├── requirements.txt                # Python dependencies
└── run-it-first.bat                # Windows helper: install deps + launch everything
```

> Trained models (`*.pkl`, `*.joblib`) are intentionally **not committed** — they're regenerated by running the notebook. See step 1 below.

## 🛠️ Prerequisites

- Python 3.x
- Flutter SDK
- Install Python deps: `pip install -r requirements.txt`
- Flutter deps install automatically via `flutter pub get`

## 🚀 Getting Started

1. **Train the ML models** (one-time, produces the `.pkl` files the API loads)
   ```bash
   pip install -r requirements.txt
   cd ML_Model
   jupyter notebook Brain_Tumor.ipynb
   # Run all cells — outputs land in Models/classification/
   ```

2. **Start the Flask API servers**
   ```bash
   python ML_Model/FlaskForClassification.py   # port 5000
   python ML_Model/FlaskForRegression.py       # port 5001
   ```

   Or explore the models visually in Streamlit:
   ```bash
   streamlit run ML_Model/app.py
   ```

3. **Run the Flutter frontend**
   ```bash
   cd flutter_ml
   flutter pub get
   flutter run
   ```

   **Windows shortcut:** from the repo root, run `run-it-first.bat` — it installs the Python deps, starts both Flask servers, and launches the Flutter desktop build.

## 💻 Usage

1. Launch the application
2. Select or drag-and-drop a brain MRI image
3. Choose a model
4. Click **Classify** to see the prediction and confidence score
